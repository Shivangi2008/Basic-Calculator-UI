# Basic-Calculator-UI
Calculator UI (HTML + CSS)
A clean and minimal user interface of a basic calculator, built using HTML and CSS.
This project focuses on layout design, responsive structure, and button styling — ideal for understanding UI fundamentals.

## 🚀 Features
Modern and simple calculator layout
Fully responsive grid-based design
Smooth hover and button interactions
Clean and readable code structure
Beginner-friendly project

## 🛠 Tech Stack
HTML5 – Structure
CSS3 – Styling, grid layout, UI design

## 📂 Project Structure
/calculator-ui

│── README.md

## 🔍 What’s Inside?
A neatly organized UI for a calculator
Styled number, operator, and action buttons
Grid layout for perfect alignment
Custom background, spacing, and typography
